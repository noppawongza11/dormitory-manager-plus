# Dormitory Manager Plus

สร้างเว็บบริหารจัดการหอพักรายเดือน โดยมีหน้าหลัก หน้าจองหอพัก หน้าแจ้งปัญหา หน้าแจ้งเตือน หน้าติดต่อเพิ่มเติม และหน้าล็อคอิน โดยให้เมนูต่างๆ อยู่ข้างบน หน้าจอหลักจะแสดงรูปภาพและรายละเอียดต่างๆ ของหอพัก เช่น ที่ตั้งอยู่ตรงไหน แมพ รายละเอียดต่างๆ ประมาณนั้น
หน้าจองหอพักมีชั้น ชั้นละ10ห้อง มีโถงทางเดินเขียนเป็นโถงชั้น1 มีบรรไดขึ้นลง กดขึ้นก็ไปชั้นต่อไป กดลงก็ลงมาชั้นเดิม ทำบรรไดขึ้นลงข้างๆกันเลยขึ้นครึ่ง ลงครึ่ง และเวลากดที่ห้องห้องพัก จะแสดงรายละเอียดต่างๆของห้องพัก และจะแสดงรูปห้องพัก สามารถกดเลื่อนดูรูปอื่นๆ ได้ ขอสัก2-3 รูป
